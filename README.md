# SyncPad Collaborative Code Workspace

Real-time collaborative code editor and markdown synchronization canvas powered by WebSockets.

---

## 🚀 Tech Stack
`React` `TypeScript` `Node.js` `Socket.io` `Express` `Tailwind CSS`

---

## ✨ Key Features
- **Multi-user**: real-time document synchronization with conflict resolution
- **Live**: cursor presence and active participant indicators
- **Instant**: markdown preview mode with side-by-side rendering
- **Room-based**: workspace creation with access controls
- **Session**: history snapshot and local backup recovery

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+) or Python (3.10+) depending on project requirements
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/aqsam-husnain/syncpad-collaborative-editor.git

# Navigate into project directory
cd syncpad-collaborative-editor

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Run the development server
npm run dev  # or: python app.py
```
